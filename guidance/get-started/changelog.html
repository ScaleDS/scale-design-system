Changelog

Every Scale release, newest first. From 4.0 the changelog covers the Lit web components that power this site, with detailed release notes on GitHub; versions up to 3.2 chart the Figma library’s evolution.

Scale v4.2

Published 28 August 2026 Lit

New

  • Agent guidance: a Markdown file for every component and foundation, 70 in all, carrying the prop contract and the judgment together. Each is generated from the page it documents, so an agent file cannot drift from what you read
  • Claude Code plugin bundling the MCP server with three skills: scale-build, scale-review and scale-migrate. One install wires up both
  • get-component-guidance on the MCP server, returning one component at a time instead of the whole catalog
  • Guidance published on the site: every page serves its own at <page-url>agent.md, indexed at /llms.txt, with the catalog at /context/*.json
  • Agents page in Get Started, covering setup and the prompts to try

Updated

  • Properties tables now list the values a prop accepts. They showed the name of a TypeScript type, which told a designer nothing. 81 props the generator was silently dropping are back, including href on Button, and components exposing CSS custom properties gained a table for them
  • The guidelines page content moved into the package, so it travels with the components it documents and an installed consumer has it offline
  • Typography foundation gained an accessibility section, covering body size, respecting the reader’s text setting, line height and length, and heading order
  • A build check now fails if a guidance file falls out of step with its page

Scale v4.1

Published 16 August 2026 Lit + Figma

New

  • Motion system: 88 tokens covering durations, easings, composite transitions, ambient loops, distances and scales. Every duration is zeroed under prefers-reduced-motion, except the loops, because a spinner that stops spinning reads as a hang
  • Motion foundation page, where every demo reads the live token or runs the real mixin, so the documentation cannot drift from the system
  • Choreography mixins for motion across more than one element: Stagger, Fade through, Shared axis, Push and Container transform. They sit outside the main stylesheet, so import them where you need them
  • Motion variables in the Figma library, with demo components for each transition and choreography pattern

Updated

  • Around 28 components moved onto the motion tokens. Banner and Toast gained real enter and exit motion, and now wait for the exit to finish before detaching
  • Tabs: label typography moved from 12px to 14px
  • Motion tokens are now served to agents through the MCP server, the token file and the agent context, so a coding agent can ask for a transition instead of inventing one
  • Guidelines site: spacing reworked across every page, and the Related section retired from component and section pages
  • Stylesheets: every SCSS file now opens with the same header and uses the same section labels, with the longer explanations moved into the documentation. No token values or rules changed

Dezin

Deprecated 24 January 2018 – March 2021 Sketch + Webflow + Figma

Before Scale there was Dezin — a design system originally built for Sketch, later turned into Webflow and Figma versions. Dezin laid the groundwork for what would become Scale, and has since been deprecated.
