# Code of Conduct

Be civil, be polite, be constructive. That's the whole rule.

It applies to every Scale space — issues, pull requests, discussions, reviews,
and anywhere you're representing the project.

**Zero tolerance.** Harassment, insults, personal attacks, discrimination,
trolling, sexualised language, or sharing someone's private information will
get your contribution removed and you banned — first offence, no warnings.
Disagreeing is fine; disagree about the work, respectfully. Blunt technical
feedback is welcome; abuse is not.

Maintainers hold themselves to the same standard.

**Reporting:** if someone crosses the line, report it privately to the
maintainers via [scaledesignsystem.com](https://scaledesignsystem.com/) or
GitHub's report feature. Reports are handled confidentially.
